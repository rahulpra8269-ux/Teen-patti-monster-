# Teen Patti Monster — Android Build

1. Create a GitHub repository named `teen-patti-monster`.
2. Upload ALL files/folders from this project.
3. Open the repository → **Actions**.
4. Select **Build Android APK**.
5. Tap **Run workflow**.
6. Wait for the build to finish.
7. Open the completed workflow → **Artifacts** → `teen-patti-monster-apk`.
8. Download the ZIP, extract it, and install `app-release.apk`.

This is a free-to-play demo. It does not implement real-money betting, deposits, withdrawals, or cash prizes.
